Climate indicators API
----------------------

In addition to the indicators classified by realm, three :py:class:`IndicatorCollection` that come with xclim are also documented in this page.

 - :py:data:`xclim.indicators.cf`, Indicators defined in `cf-index-meta`.
 - :py:data:`xclim.indicators.icclim`, Indicators defined by ECAD, as found in the python package Icclim.
 - :py:data:`xclim.indicators.anuclim`, Indicators of the Australian National University's Fenner School of Environment and Society.
